      Built around three jobs

      Remember what you copied, reshape it, and use it in your own workflow. Each feature earns its place by removing a step.

      Remember

      Everything is sorted the moment you copy it.

      Smart categories
      Text, images, code, colors, and links are tagged automatically, so you filter instead of scrolling.
      Snippet folders
      Pin terminal commands, boilerplate, and signatures. They stay put when history rolls over.
      Instant fuzzy search
      Typing starts filtering the second the overlay opens. No click to focus, and typos still match.

      Reshape

      Fix the text before it lands.

      Paste queue
      Copy five things, paste five things, in order. No window juggling.
      Paste formatting
      Plain text, casing, trimmed whitespace, or decoded Base64, chosen at paste time.
      Quick edit
      A mini editor inside the overlay, so a small fix doesn’t need another app.

      Automate

      For developers and power users.

      Syntax highlighting
      JSON, XML, SQL, and Rust are detected and pretty-printed in the preview.
      Placeholders
      Use {date}, {clipboard_state}, and {cursor} in pinned snippets.
      Action webhooks
      Send a copied string to a local script or a CI trigger.

      Private by default

      A clipboard sees everything you copy, so Zlip is strict about what it keeps and for how long.

      • Password managers are ignoredBitwarden, 1Password, and similar apps are blocklisted from the first launch.
      • Secrets expire in 60 secondsHigh-entropy strings such as API keys and card numbers are cleared automatically.
      • Memory is wiped, not just freedSensitive buffers are zeroed in Rust when they are dropped.
      • Every shortcut and rule is yoursRetention, blocklists, and themes live in a TOML file or the settings screen.

      Soft color, clear structure

      Each kind of clip gets its own pastel, so you recognize items by color before you read them. Select a swatch to copy its hex code.

      Glass that stays readable

      A 24 px blur with a thin bright edge lets the desktop show through while text keeps its contrast.

      Search sits on top

      The search field is the first thing under your cursor, because filtering is the most common action.

      Motion explains change

      Items expand, queue, and paste with short transitions that show what moved. Reduced-motion settings are respected.

      Shipped by a pipeline you can read

      Every release goes from a version tag to a signed Windows installer and a Winget pull request, with no manual steps in between.

      1. Validate the tagThe tag must match the versions in Cargo.toml and tauri.conf.json.
      2. Pass the CI gateThe release reuses the same CI checks that run on every pull request.
      3. Build installersOne run produces an .exe and an .msi, then adds SHA256 sums and a provenance attestation.
      4. PublishA draft release carries the installers and updater signatures.
      5. Open the Winget PRThe pipeline hashes the public installer, writes the manifests, and submits to winget-pkgs.
