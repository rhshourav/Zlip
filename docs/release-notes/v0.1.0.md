> The first release of Zlip: a fast, private clipboard manager that replaces the Windows clipboard panel with a compact, glass-styled overlay.

<!-- prerelease -->
**This is a pre-release for testing.** It is not published to Winget. Please report anything odd, with the log file attached (see "If something goes wrong").

<!-- /prerelease -->
## Highlights

- **One shortcut, instantly.** Press `Win+V` to open a compact overlay (360 × 500) next to your text cursor. Type to search; fuzzy matching finds "docker" from "dkr".
- **A shortcut that keeps working.** A backup shortcut (`Ctrl+Alt+V`) opens Zlip even if `Win+V` is interrupted, and Settings has a one-click **Reconnect**.
- **Private by design.** History is encrypted on disk. Passwords and API keys stay in memory only, expire after a minute, and copies from password managers are skipped.
- **Settings screen.** Shortcuts, theme, window size, history limits and more. Every change applies instantly and is saved for you.
- **Power tools when you want them.** Paste queue, paste-as formatting (`camelCase`, `snake_case`, Base64 decode, clean links), snippet folders and a quick editor.

## What's in the box

| | |
| --- | --- |
| **Looks** | A quiet, Apple-style interface: a small coloured tile marks each item's kind, with Light, Dark and Auto themes. Windows 11 gets native acrylic with rounded corners; Windows 10 gets a square panel. |
| **Kinds** | Text, links, code (highlighted), images, colours, files, snippets and secrets, each recognised automatically. |
| **Paste** | `Enter` pastes, `Shift+Enter` pastes as plain text, `Alt+1`…`Alt+9` pastes the first nine results, `Tab` expands an item to edit or inspect it. |
| **Queue** | `Ctrl+Shift+Q`, copy several things, `Ctrl+Shift+Q` again, then `Ctrl+V` pastes them in order. |
| **Settings** | Open it with the sliders button or from the tray icon. Advanced options (snippets, script actions, automations, privacy lists) live in `%APPDATA%\zlip\config.toml`, which reloads the moment you save it. |

## Install

<!-- winget -->
**Winget:** `winget install rhshourav.Zlip`. Update later with `winget upgrade rhshourav.Zlip`; remove with `winget uninstall rhshourav.Zlip`.

<!-- /winget -->
**Installer:** download `Zlip_{{version}}_x64-setup.exe` (a normal installer) or `Zlip_{{version}}_x64_en-US.msi` (for managed PCs) from the assets below. Needs Windows 10 (1903 or later) or Windows 11. Windows 11 already includes the WebView2 runtime Zlip uses; on Windows 10 the installer downloads it if it is missing.

**Silent install** (scripts, Intune): `msiexec /i Zlip_{{version}}_x64_en-US.msi /qn`

**Verify your download** against `SHA256SUMS.txt` on this page:

```powershell
(Get-FileHash .\Zlip_{{version}}_x64_en-US.msi -Algorithm SHA256).Hash
```

<!-- unsigned -->
> **Windows SmartScreen may warn on first run** ("Windows protected your PC") because these installers are not code-signed yet. Choose **More info**, then **Run anyway**, after checking the hash above.

<!-- /unsigned -->
Zlip runs from the tray: closing the overlay does not quit it. Use the tray icon's **Quit Zlip** to exit fully.

## Good to know

- **Zlip replaces Windows' own `Win+V` panel** while it runs. Quit Zlip and the Windows panel returns.
- **Apps running as administrator ignore Zlip.** Windows does not let a normal program watch keys typed into an elevated window, so `Win+V` will not open over one.
- **Your data lives in two places:** settings in `%APPDATA%\zlip\`, history and logs in `%LOCALAPPDATA%\zlip\`.

## Known limitations

- No automatic updates yet: download new versions from this page.
- No "start with Windows" option yet.
- Rich-text/HTML capture is not supported: text, files and images are captured.
- Snippet folders are defined in the settings file; creating them in the interface is not built yet.

## If something goes wrong

- **`Win+V` does nothing:** press the backup shortcut `Ctrl+Alt+V`, then open Settings → **Reconnect** (or tray icon → *Shortcut not working? Reconnect*).
- **Report a problem:** open an issue at https://github.com/{{repo}}/issues and attach the log from Settings → **Log files → Open**.
- **Uninstall:** Settings → Apps → Zlip.
